Enterprise Architecture & Data Security Specifications

Architecture Rationale: Abhivanta is engineered as a high-performance web application utilizing modern browser standards. By leveraging versioned localStorage with strict schema sanitization and JSON export/restore capabilities, the system provides offline reliability, instant data portability, and immediate dispatch visualization. Industrial deployment connects the telemetry bus directly to an MQTT/Modbus TCP SCADA inverter gateway with TLS 1.3 encryption.
